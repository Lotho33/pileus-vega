# Pileus for Vega OS

**Version 1.0.0** · Vega OS 1.2+ · armv7 · package `com.lotho33.pileus`

**Pileus for Vega OS** is the [Pileus](https://github.com/Lotho33/pileus)
client for Amazon Fire TV devices running **Vega OS**, built with React Native
for Vega. It talks to a self-hosted [Mycelium](https://github.com/Lotho33/mycelium)
media server. Every other platform (Android TV, Fire OS, mobile, desktop, web,
smart TVs) uses the Flutter app in the main repository; this one targets
Vega only.

### What Pileus is not

- **Not a content service.** The app ships with no content sources of its
  own. What it can browse and play is entirely defined by the Mycelium server
  (and its plugins) you point it at.
- **Not standalone.** It needs a Mycelium server you run yourself, reachable
  on your local network or over HTTPS.

The app has no analytics, advertising or tracking and talks only to the
server address you enter. See the
[privacy policy](https://github.com/Lotho33/pileus/blob/main/docs/PRIVACY.md).

> **Language:** the interface is Italian-only for now.

## How it works

The contract with the server is the same as the Flutter app's: the
`proto/*.proto` files, spoken over **gRPC-Web**
(`<origin>/grpc/mycelium.<Service>/<Method>`). HLS playback uses
`@amazon-devices/react-native-w3cmedia` with Amazon's patched Shaka Player;
progressive files use the player's URL mode.

## Building

Requirements: the [Vega SDK and CLI](https://developer.amazon.com/docs/vega/),
Node.js 18+, and Docker (only to build the Shaka Player bundle).

```sh
npm install
scripts/fetch-shaka.sh        # Amazon's patched Shaka Player → src/vendor/ (not versioned)
npm run typecheck && npm test && npm run lint
npm run build:release         # .vpkg files in build/<arch>-release/
```

| Command | What it does |
|---|---|
| `scripts/fetch-shaka.sh` | Downloads and builds Amazon's patched Shaka Player into `src/vendor/shaka/`. Run it after cloning: the folder is not versioned because Amazon's polyfills are proprietary. Uses a throwaway `eclipse-temurin:21-jdk` container |
| `node scripts/gen-gradients.mjs` | Regenerates the gradient ramps (`src/gradients/png`, `assets.ts`) from `src/gradients/defs.json` |
| `scripts/sync-proto.sh <pileus checkout>` | Copies the protos from the main repository and regenerates `src/gen` |
| `scripts/deploy.sh <device-ip:port>` | Release build, then an in-place **upgrade** on a developer-mode device that keeps the app's data (`vega run-app` uninstalls first, which wipes the session) |
| `scripts/perf-log.sh <device-ip:port>` | Streams the profiling summaries (`src/core/perf.ts`): gRPC round trips, D-pad step → focus, hero image loads, Play → first frame, late JS frames per screen, Hermes heap |

## Layout

```
proto/            contract with Mycelium (copied from the main repository)
src/gen/          TypeScript generated by ts-proto (do not edit by hand)
src/core/         gRPC-Web over XHR, server address, session, Mycelium client
src/state/        connect → pair → profile flow
src/screens/      top-level screens
src/components/   remote-friendly focusable components
src/home/         home rows, hero, quick search
src/search/       full search and filters
src/details/      details pages, sources, episode and live popups
src/player/       player: Shaka for HLS, URL mode for files
src/vendor/       patched Shaka Player (generated, not versioned)
```
